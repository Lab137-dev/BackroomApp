# Backroom Ops

A mobile-first browser tool for coordinating a retail backroom shift.

Backroom Ops was designed from firsthand experience with unloading, sorting, processing, staffing, breaks, back stock, and end-of-day reporting. It runs entirely in the browser with no server or installation required.

## Features

- Track Standard, 2-Wave, and 4-Wave pallets
- Set configurable time targets and see overdue alerts
- Record cartons and pieces by pallet type
- Assign staff to unloading, sorting, hanging, and processing
- Track working, break, and lunch status
- Record audit items and ready-for-floor back stock
- Generate an end-of-day operational summary
- Export and import JSON backups
- Save active data locally in the browser
- Responsive layout for tablets, phones, and desktop browsers

## Run it

1. Download `index.html`.
2. Open it in a modern browser.
3. For the best tablet experience, use fullscreen mode.

No build step or external dependencies are required.

## Data and privacy

The application stores its working data in the browser's `localStorage`. Nothing is transmitted to a server by the application. Export a JSON backup before clearing browser data or moving to another device.

## Project status

Working prototype. The current version is intended for real-world testing and iterative improvement rather than production deployment across an organization.
